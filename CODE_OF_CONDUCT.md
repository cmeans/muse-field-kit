# Code of Conduct

This project adopts version 2.1 of the [Contributor Covenant](https://www.contributor-covenant.org) as its Code of Conduct. The full text is canonical at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

Everyone taking part is expected to follow it in every project space: issues, pull requests, discussions, and any channel linked from this repository.

## Scope

This Code applies within all project spaces, and also when someone is officially representing the project in public spaces.

## Reporting a concern

This is a one-person project with no shared inbox, so reports go through the same private channel as security reports:

1. Open a **GitHub private security advisory** at <https://github.com/cmeans/muse-field-kit/security/advisories/new>.
2. Put `Conduct` in the title, so it isn't mistaken for a security report.
3. Describe what happened, link any relevant public threads, and say how you'd like it handled.

GitHub doesn't offer a private contact channel for anything but security, so this is a workaround: an advisory is the only private thread the maintainer can see and answer without exposing the discussion. Reports are handled confidentially.

## Enforcement

The maintainer reviews reports and decides on the response, following the Contributor Covenant's enforcement guidelines.
