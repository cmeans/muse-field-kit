# Security policy

- **Encrypted credential handoff** (the security-sensitive folder in this repo): see `encrypted-credential-handoff/SECURITY.md` for scope and reporting guidance. Preferred route is a private security advisory on this repository (GitHub → Security → Advisories). Please do not open a public issue containing exploit detail for an unpatched flaw.
- **Everything else in the kit** (guides and patterns): open a normal issue; there is no embargo expectation for documentation problems.
