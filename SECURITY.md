# Security policy

- **Encrypted credential handoff** (the security-sensitive folder in this repo): see `encrypted-credential-handoff/SECURITY.md` for scope and reporting guidance. Report privately at https://github.com/cmeans/muse-field-kit/security/advisories/new (or: this repository's **Security and quality** tab, which may be under the "…" menu on a narrow window, then **Report a vulnerability**). You need to be signed in to GitHub. Only you and the repository's maintainers see the report. Please do not open a public issue containing exploit detail for an unpatched flaw.
- **Everything else in the kit** (guides and patterns): open a normal issue; there is no embargo expectation for documentation problems.
